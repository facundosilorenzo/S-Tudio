# S-Tudio · Cleared

Repaso para los exámenes de 1º de Comercio Internacional: esquemas por tema, flashcards, tests con corrección automática, ejercicios de cálculo y simulacros de examen.

Toda la app está en `index.html` (una sola página, sin instalación). Se publica con GitHub Pages desde la rama `main`, carpeta raíz.

El progreso se guarda en el navegador de cada persona.
